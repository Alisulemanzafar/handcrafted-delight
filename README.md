# Handcrafted Delight — GitHub Pages Website

A responsive static website made for **Handcrafted Delight** and linked to Instagram **@handicrafts_pk**.

## Files
- `index.html` — website content
- `styles.css` — all styling and mobile responsiveness
- `script.js` — mobile menu, reveal animations, cursor glow
- `assets/logo.png` — transparent Handcrafted Delight logo

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new repository, for example `handcrafted-delight`.
2. Upload **all files and the `assets` folder** from this project to the repository root.
3. Open the repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. After GitHub finishes publishing, your site will be available at a URL similar to:
   `https://YOUR-USERNAME.github.io/handcrafted-delight/`

## Customize
Search `index.html` for `https://www.instagram.com/handicrafts_pk/` if you ever want to change the Instagram link.

The website currently uses Instagram as the shop/order channel, so there is no checkout or payment system included.
